# Monopoly Game (Pygame)

A local multiplayer Monopoly clone for my grade 12 computer science culminating project.

## Features
- 2–8 players
- Buy properties, collect rent
- Chance and Community Chest cards
- Jail system with pay/roll options
- Save / load game (3 slots)

## Requirements
- Python 3.8+
- Pygame

## How to Run
1. Install Pygame: `pip install pygame`
2. Run: `python main.py`
